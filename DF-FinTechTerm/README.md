# DF-FinTechTerm

This is the application directory for the unified Finance Tools CLI. Setup,
configuration, and the complete user-function inventory are in the repository
[root README](../README.md).

Run `./df-fintechterm help` for command groups and append `--help` for options.
Orders default to Alpaca paper trading; live orders require `--live` and the
literal `LIVE` confirmation. No terminal UI is included.
