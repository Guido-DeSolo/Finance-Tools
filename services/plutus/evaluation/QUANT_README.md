# Frozen QUANT benchmark v1

The benchmark covers supportive (PFE), bearish/conflicting (OTLK), strong momentum
(CAMP), suspicious partial data (HEPA), and rejected data (ATTO). ATTO must produce
a deterministic `ABSTAIN` without invoking Ollama.

Readiness is all-or-nothing:

- 100% structural validity
- zero unsupported claims
- zero incorrect evidence references
- zero availability contradictions
- zero invented statistics
- correct deterministic abstention

Latency is recorded but never scored. This benchmark performs no database reads,
writes, synthesis, or persistence.
