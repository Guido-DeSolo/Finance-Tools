# Frozen synthesis benchmark v1

Qwen3 receives only normalized insider, quant, and news branch outputs. The corpus
tests aligned bullish evidence, aligned bearish evidence, irreconcilable opposing
branches, one-branch sparsity, and non-directional evidence.

Readiness requires 100% structural validity, no invented evidence sources, no
contradictions with branch directions, correct abstaining-branch handling,
coherent stance/action, correct insufficient/inconsistent terminal statuses, and
no unsupported causal claims. Latency is recorded but not scored. There is no
persistence or batch mode.
