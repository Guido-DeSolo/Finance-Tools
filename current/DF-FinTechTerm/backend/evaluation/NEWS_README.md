# Frozen NEWS benchmark v1

The synthetic corpus isolates five unambiguous behaviors: positive guidance,
negative regulatory news, conflicting earnings/guidance articles, low-information
conference noise, and no recent news. The NONE case must abstain without invoking
Ollama.

Readiness requires 100% structural validity, correct article references, no
invented catalyst, supported sentiment, correct abstention, and internally
consistent article/overall sentiment. Latency is recorded but not scored. The
benchmark performs no persistence or synthesis.
